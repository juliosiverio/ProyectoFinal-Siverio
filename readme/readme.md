# Conversor de Monedas

Aplicación que convierte monedas usando un JSON simulado como base de datos.

## Funcionalidades:
- Ingresar monto y seleccionar monedas de origen y destino.
- Ver el resultado de la conversión.
- Guardar el historial de conversiones.
- Borrar historial.

## Tecnologías usadas:
- HTML
- CSS
- JavaScript
- Web Storage (localStorage)
- Fetch API
